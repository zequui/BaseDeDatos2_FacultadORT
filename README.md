# Repositorio de Obligatorios - Bases de Datos 2 (ORT)

Este repositorio contiene el desarrollo completo del obligatorio de la materia **Bases de Datos 2** de la Facultad de Ingeniería de la Universidad ORT Uruguay. El objetivo es documentar el proceso de análisis, diseño e implementación de soluciones relacionales y NoSQL aplicadas al escenario propuesto.

## 📚 Contenido

- Modelado relacional del sistema Moltbook
- Análisis y documentación de restricciones de integridad
- Scripts DDL y generación de datos de prueba
- Implementación de procedimientos, funciones y servicios requeridos
- Consultas SQL y análisis de planes de ejecución
- Diseño del modelo NoSQL en MongoDB
- Integración entre Oracle y MongoDB
- Consultas analíticas sobre eventos y trazabilidad de agentes
- Documentación técnica y decisiones de diseño

## 🧠 Objetivos

- Aplicar conceptos avanzados de modelado relacional
- Implementar restricciones estructurales y no estructurales
- Diseñar e implementar servicios sobre bases de datos relacionales
- Analizar rendimiento y planes de ejecución SQL
- Modelar información semiestructurada en MongoDB
- Integrar tecnologías relacionales y NoSQL
- Desarrollar soluciones orientadas a trazabilidad y analítica de eventos

## 🛠️ Tecnologías utilizadas

- Oracle Database
- MongoDB
- SQL / PL-SQL
- Scripts de integración y migración de datos
